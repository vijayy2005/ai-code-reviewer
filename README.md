# 🤖 AI Code Reviewer

An AI-powered Code Reviewer built with **Python**, **Streamlit**, **Flake8**, **Black**, and **Radon** to automatically analyze Python code, detect style violations, measure code complexity, suggest improvements, and generate reports.

---

# 📌 Project Overview

Writing clean, maintainable, and error-free code is an essential skill for every software developer. Reviewing code manually can be time-consuming and inconsistent.

The **AI Code Reviewer** automates the code review process by analyzing Python code using industry-standard tools. It checks coding standards, identifies style issues, measures code complexity, and provides developers with actionable suggestions to improve their code quality.

This project helps developers write cleaner, more maintainable, and production-ready code.

---

# 🚀 Features

- 📂 Upload Python (.py) files
- ✍️ Paste Python code directly
- 🔍 Analyze code using **Flake8**
- 🎨 Format code with **Black**
- 📊 Measure Cyclomatic Complexity using **Radon**
- 📈 Display code quality metrics
- 📋 Show detailed improvement suggestions
- 📥 Export analysis reports
- 💻 Interactive Streamlit Dashboard

# ⚙️ Installation



# 📖 How It Works

### Step 1

Upload a Python (.py) file or paste Python code.

### Step 2

The application analyzes the code using:

- Flake8
- Black
- Radon

### Step 3

The system detects:

- Style Issues
- Syntax Errors
- Formatting Problems
- Complexity Level
- Code Quality

### Step 4

Results are displayed on the dashboard with suggestions for improvement.

### Step 5

Export the analysis report for future reference.
